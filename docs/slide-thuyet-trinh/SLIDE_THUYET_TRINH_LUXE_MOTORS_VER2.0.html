04. Xử Lý Giao Dịch

Mongoose Client Session ACID Transaction

Bảo đảm tính toàn vẹn tuyệt đối khi trừ tồn kho xe và khởi tạo đơn cọc đồng thời.

⚡ Luồng Xử Lý Atomicity

  • Bắt đầu `mongoose.startSession()` và `session.startTransaction()`.
  • Thực hiện `Car.findOneAndUpdate` trừ `stockCount` với điều kiện `stockCount > 0`.
  • Tạo bản ghi `Order.create` chứa thông tin cọc và thông tin khách hàng.
  • Nếu thành công: `commitTransaction()`. Nếu bất kỳ lỗi xuất hiện: `abortTransaction()`.
const session = await mongoose.startSession(); session.startTransaction(); try { const car = await Car.findOneAndUpdate( { _id: carId, stockCount: { $gt: 0 } }, { $inc: { stockCount: -1 } }, { new: true, session } ); if (!car) throw new Error('Xe đã hết hàng'); const order = await Order.create([{ ... }], { session }); await session.commitTransaction(); return order[0]; } catch (err) { await session.abortTransaction(); throw err; }

14. An Ninh & Audit

Khắc Phục 44 Vulnerabilities / Issues (P01 - P41)

Nhật ký gia cố an ninh & chuẩn hóa mã nguồn backend/frontend.

🛡️ P01 - Rate Limiter IP

Triển khai Custom Memory Rate Limiter theo IP: Auth 10 req/15m, Chat 15 req/1m, API 100 req/1m.

🔒 P19 - NoSQL Injection

Tích hợp `mongoSanitizeMiddleware` loại bỏ triệt để các toán tử độc hại (`$gt`, `$ne`, `$where`).

🌐 P04 - CORS Whitelist

Khóa chặt CORS origin theo danh sách whitelist cụ thể, loại bỏ lỗ hổng wildcard `.vercel.app`.
