## 🚀 3 PHƯƠNG PHÁP TẠO SLIDE CANVA NHANH NHẤT

### 🌟 PHƯƠNG PHÁP 1: DÙNG TÍNH NĂNG "CANVA DOCS TO DECK" (KHUYÊN DÙNG - 1 CLICK)

1. Mở trang chủ **[Canva.com](https://www.canva.com)**.
2. Chọn **Tạo thiết kế** -> Chọn **Canva Docs** (Tài liệu).
3. Mở file **`docs/canva/CANVA_DOCS_TO_DECK.md`** (hoặc copy khối nội dung ở phần bên dưới).
4. Dán toàn bộ nội dung vào trang Canva Docs vừa tạo.
5. Nhấn nút **Chuyển đổi (Magic Switch / Convert to Presentation)** ở góc trên bên phải.
6. Chọn chủ đề màu **Obsidian Gold / Luxury Executive Dark** do Canva gợi ý.
7. 🎉 **Hoàn thành**: Canva sẽ tự động sinh ra 16 slide trình chiếu sắc nét, chuẩn bố cục!

---

### 📊 PHƯƠNG PHÁP 2: DÙNG ỨNG DỤNG "BULK CREATE" (TẠO HÀNG LOẠT TỪ CSV)

1. Mở Canva -> Chọn **Tạo thiết kế** -> **Thuyết trình (Presentation 16:9)**.
2. Tìm kiếm và chọn một Template phong cách sang trọng (Gõ từ khóa: `Luxury Car`, `Dark Gold Executive`, `Modern Business`).
3. Nhìn sang thanh menu công cụ bên trái -> Chọn **Ứng dụng (Apps)** -> Tìm ứng dụng **Tạo hàng loạt (Bulk Create)**.
4. Chọn **Tải tệp CSV lên (Upload CSV)** -> Chọn file **`CANVA_BULK_CREATE_SLIDES.csv`**.
5. Nhấp chuột phải vào từng khung văn bản trên Slide mẫu -> Chọn **Kết nối dữ liệu (Connect Data)**:
   - Tiêu đề chính -> Chọn `SlideTitle`
   - Phụ đề -> Chọn `SlideSubtitle`
   - Ý 1, Ý 2, Ý 3, Ý 4 -> Chọn `Point1`, `Point2`, `Point3`, `Point4`
6. Bấm **Tiếp tục (Continue)** -> **Tạo slide (Generate Slides)**.
7. 🎉 **Hoàn thành**: 16 slide sẽ được Canva tự động tạo hàng loạt chỉ trong 5 giây!

---

### 📄 PHƯƠNG PHÁP 3: NHẬP TỪ PDF TỰ ĐỘNG (IMPORT PDF TO CANVA)

1. Mở file **`SLIDE_THUYET_TRINH_LUXE_MOTORS_VER2.0.html`** bằng trình duyệt Google Chrome hoặc Edge.
2. Bấm phím **`Ctrl + P`** (In trang) -> Ở mục Máy in chọn **Lưu dưới dạng PDF (Save as PDF)** -> Bấm **Lưu**.
3. Vào trang chủ Canva -> Chọn nút **Tải lên (Upload)** ở góc trên bên phải -> Chọn file PDF vừa lưu.
4. 🎉 **Hoàn thành**: Canva sẽ giải mã file PDF và biến 100% chữ, màu sắc, hình ảnh thành các phần tử thiết kế cho phép bạn chỉnh sửa kéo thả trực tiếp!
